# Labirintus-gyár

Gyerekeknek szóló nyomtatható rejtvények, magyar és angol nyelven:

- **Labirintus** (index.html): játszható labirintus, egyéni nehézség, alakzatok, PDF-export.
- **Labirintusok nyomtatása** (nyomtatas.html): több labirintus egyszerre, PDF-ben.
- **Rejtvények** (rejtvenyek.html): szókereső, pontösszekötő, számpiramis, varázsnégyzet, betűkeverő és hibakereső, korosztály szerint (6–7, 8–9, 10–12 év), PDF megoldásokkal.

Élő oldal: https://attilaborbas.github.io/labirintus-gyar/
